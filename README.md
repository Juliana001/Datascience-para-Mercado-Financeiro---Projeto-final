## Descrição: o projeto é um robô que deve decidir se o investidor deve comprar, vender ou não operar, visando maximizar os ganhos e minimizar as perdas. Em um cenário mais específico, o robô deve prever qual será o melhor momento para compra e venda, baseando se na análise do GAP de  abertura.

## Tecnologias utilizadas: 
### Python
* Numpy
* Pandas
* Scikit-Learn
* Matplotlib
* Seaborn

## Metodologia:
* Estudo do caso
* Entendimento dos dados
* Criação do dataset
* Validação do dataset com modelos lineares
* Criação do modelo do robô
* Simulação com o modelo

## Estrutura do Repositório

O projeto está organizado nas seguintes pastas principais:

* Apresentações feitas na disciplina:
    * Contém os pdf's das apresentações de progresso e resultados finais realizadas durante a disciplina. Documenta a evolução do pensamento e as decisões de projeto.
* Códigos:
    * Armazena os scripts e notebooks utilizados no desenvolvimento.
* Datsets:
    * Contém os ficheiros de dados utilizados, incluindo o dataset final utilizado (dataset4.csv) e versões anterioes para registro.
* Relatório:
    * Pasta destinada ao relatório técnico final que detalha a metodologia, resultados e conclusões do trabalho.
* LOGBOOK:
    * Diário de bordo do projeto. Regista cronologicamente o progresso, as dificuldades encontradas, as decisões tomadas e os próximos passos.
